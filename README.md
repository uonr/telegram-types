# Telegram Types

[![Maintenance status: unmaintained](https://img.shields.io/badge/maintenance-unmaintained-red.svg)](#maintenance-status)

## Maintenance status

This crate is no longer maintained and its Telegram Bot API definitions are
outdated. For new projects, consider using one of these actively maintained
alternatives:

- [`frankenstein`](https://github.com/ayrat555/frankenstein) if you need
  Telegram Bot API types or a low-level API client. With no client feature
  enabled, it can also be used primarily as a types crate.
- [`teloxide`](https://github.com/teloxide/teloxide) if you need a complete
  framework for building Telegram bots.

[Documentation](https://docs.rs/telegram_types/)

Types in the Telegram Bot API and their deserializers

See also [Telegram Bot API](https://core.telegram.org/bots/api) and [changelog](https://core.telegram.org/bots/api-changelog).
